# AIOS Auto Editor v0.2.0-rc1

## Highlights

- Timeline editing with V1, V2, and A1 tracks
- Native FFmpeg export with progress, cancellation, retry, and diagnostics
- Autosave and session recovery after unclean shutdowns
- Guided relinking for offline source media
- Large-project timeline performance guard
- Automated Windows packaging QA and release-readiness validation

## Validation target

This release candidate must pass the automated Windows QA workflow and the manual checks in `docs/RELEASE_CHECKLIST.md` before promotion to v0.2.0 stable.

## Known limitations

- V2 overlays are full-frame and do not yet expose transform or opacity controls
- A1 mixing does not yet expose per-clip volume controls
- Manual installer and export smoke tests are still required on Windows hardware
